## 4 消融有效性检查（量化）

### 4.1 算法（可复现，写死在这里）

- **多字短语重合率**：把回答里的标点与空白全部去掉 → 取所有长度为 **4** 的连续字符子串（4-gram）构成集合 P。`jaccard = |P∩Q| / |P∪Q|`；`containment = |P∩Q| / min(|P|,|Q|)`。
- **数值集合 Jaccard**：先把回答里的日期时间戳（`2026-10-21T16:00:00` / `2026年10月21日16:00`）和标识符 / 版本号（`b06-20261020-v1`、`s1-live-001`）清掉，再用 `\d+(?:\.\d+)?` 抽出浮点数集合 Na / Nb，`jaccard = |Na∩Nb| / |Na∪Nb|`。（清掉日期是因为两个锚点的采样时间本来就不同，不清会把“时间戳不同”算成“认知不同”。注意抽数**不用**否定环视 `(?<!\w)` —— Python 的 `\w` 在 Unicode 下把汉字也算词字符，会把“温度为32.8℃”里的 32.8 一起挡掉。）
- **历史引用**：取历史温度序列**除最后一个点以外**的值（最后一个点 = 当前温度，否则每篇回答都会“命中”当前值），看回答的数字集合里出现了其中几个 —— 这是“回答确实在谈过去的过程”的硬证据。
- **预测引用**：只看 ③ 块真正渲染给 LLM 的那几个量（confidence / confidence_normal / confidence_watch / dtw_temperature / dtw_humidity / dtw_lux）与 predicted_attention 等级字符串。
- 以上四组指标**都不依赖模型、不依赖随机数**，同样的两段文本永远得到同样的数。
