## 结论

```text
【结论】

创新点 3 证明了什么：
  1. 三次运行（run_109 / run_082 / run_084）在 anchor、历史窗口、B06 窗口、知识 query、固定问题、system prompt 全部一致的前提下，只有天气条件不同 —— 而系统的结论档位、是否表达分歧、是否说明受限、判断范围全部随之改变。这说明判断不是照抄上一句话，而是由证据条件决定的。
  2. 证据出现分歧时（run_082），系统输出 conflict_unresolved，supporting 与 opposing 两列都非空，回答里同时出现『支持提高关注』与『提示可能缓解/反向』两类表达 —— 分歧被保留下来，没有被投票抹平。
  3. 证据缺失时（run_084），系统明确说出外部天气不可用、相关判断受限，同时仍然给出历史与模型能给的判断 —— 这就是『哪些判断还能继续 / 哪些应该停下来』。
  4. 没有偷偷补齐：run_084 的回答里外部天气表述与数值命中 0 处。
  5. 没有越界说确定话：run_082 的回答里确定性词表命中 0 处。

创新点 3 没有证明什么（不许夸大）：
  1. 没有证明系统在**任何**证据组合下都表现正确 —— 本轮只覆盖三种外部条件，每种一次采样。
  2. 没有证明 LLM 的措辞层面**从不**越界 —— 词表只覆盖列出的多字短语，是启发式检测，不是语义判定。
  3. 没有证明系统能在**证据方向不一致且外部更差**时同样保守 —— 本轮只造了『同向』和『反向』两种外部条件。
  4. 没有证明在**缺少内部证据**（例如历史窗口本身取不到）时也成立 —— 本轮的缺失只发生在外部天气这一路。
  5. 没有证明模型改 prompt 之后这些性质仍然成立 —— 本轮**没有改** SYSTEM_PROMPT，也没有做改动前后的对照。
  6. 没有证明『结论档位字符串』在证据缺失时一定改变 —— 实测run_109 与 run_084 的 combined_attention.value **同为 watch_internal**（变化体现在 external_signal / reason / 证据构成与回答措辞上）。这是本轮必须如实写出来的一条。
```

## Limitations

```text
【Limitations】

L1 本轮只新跑 1 次 LLM（run_agree），run_conflict / run_missing_weather 复用 S4/S5 已落盘的 run，避免采样波动。三次运行因此不是同一次采样内的对照。

L2 run_agree 的天气是离线夹具构造的 external_deteriorating（case=deteriorating），**不是真实气象**。离线夹具保证可复现，但它的数值分布不等于真实天气。

L3 确定性断言检测（C2）与『偷偷补齐』检测（C4）都是启发式多字短语 + 数值正则匹配，可能漏判或误判。报告给出了实际命中的句子原文，供人工核对；命中数必须结合原句人工确认，不能只看计数。

L4 本轮 LLM 为 qwen-max（原 qwen3.5-27b 免费额度耗尽后更换），与 S1–S3 的措辞不可直接比较。

L5 三次运行的唯一变量是天气条件：历史窗口、B06 窗口、知识 query、固定问题、system prompt 全部一致（本报告用 window_id / question_sha256 / system_prompt_sha256 打印自证）。但『一致』由存档字段核对，不是逐字节 diff 两次完整输入。

L6 『判断范围收缩』是语义判断。机器检查只能验证『降级后回答里出现了 / 没出现某些表达』，不能证明模型真的收窄了推理范围。

L7 实测 run_109 与 run_084 的 combined_attention.value 相同（watch_internal），所以 C3 判定的是**记录层**（external_signal / reason / 证据构成）发生变化，而不是档位字符串发生变化。根因是 combined_attention() 的分支顺序：predicted=WATCH 分支先于外部信号分支命中。

L8 文档 p.51–55 的原文不在仓库 docs/ 下，本报告的六步要点是按该页转述的，不是逐句引用原文。
```
